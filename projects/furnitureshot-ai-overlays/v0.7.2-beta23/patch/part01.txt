+# FurnitureShot AI v0.7.2-beta23 — Reference Match Audit
+
+Target: move the product rendering from the beta22/app look toward the supplied premium studio reference **without redesigning the product**.
+
+## Root cause found in beta22
+
+The strongest pipeline-level issue was not simply sharpening. `LocalEnhancementEngine.processAttempt()` replaced the decoded original with an already tone-mapped/enhanced bitmap before segmentation and before the later restoration/material/photometric/high-frequency gates. That meant the later "original-vs-result" checks were not using the true decoded photograph as their source of truth.
+
+beta23 keeps the decoded original alive through:
+
+- segmentation;
+- full-resolution matte refinement;
+- structure comparison;
+- localized restoration;
+- texture/detail recovery;
+- photometric comparison;
+- artifact detection;
+- shadow/contact analysis.
+
+## Visual reference diagnosis
+
+Compared with the supplied reference, the current app result is visibly flatter and more washed. On the supplied JPEG pair, simple full-frame diagnostics also show lower tonal/edge richness in the app result:
+
+- mean luminance: app ~0.867 vs reference ~0.732;
+- luminance standard deviation: app ~0.175 vs reference ~0.211;
+- mean simple edge energy: app ~0.0122 vs reference ~0.0255.
+
+These are not acceptance metrics by themselves because framing/background differ, but they support the visual diagnosis: the current result is brighter/flatter and carries substantially less local edge/texture energy.
+
+## beta23 changes
+
+- `QUALITY_MAX`, `BALANCED`, `FAST` processing profiles.
+- QUALITY MAX preserves the decoded original as the pixel truth source.
+- segmentation guide resolution: 1536 px max edge in QUALITY MAX, 1280 BALANCED, 896 FAST.
+- `StructureLockController`: strong alpha/structural edges are pulled back toward original pixels; no geometry warp is ever used as a repair.
+- `ArtifactDetector`: rejects excessive novel edges, oversharpen/double edges, clipping and edge color drift.
+- profile-aware material, lighting and original-detail strength.
+- high-frequency recovery remains original-derived and tiled; QUALITY MAX can use a stronger recovery multiplier while remaining gate-limited.
+- contact-only occlusion fallback starts exactly at detected ground supports; no ellipse/blob/drop shadow.
+- removed beta22 post-composite hole filling that could close real gaps between slats.
+- low-alpha edge decontamination no longer divides by near-zero alpha, reducing colored halos.
+- QUALITY MAX avoids meaningful digital enlargement during final placement.
+
+## Acceptance direction
+
+A beta23 candidate is allowed to improve tone/material only if structure and artifact checks remain within conservative bounds. If it fails, the pipeline falls back toward the true original product pixels rather than hallucinating a repair.
