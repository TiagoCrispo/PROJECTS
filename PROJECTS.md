## Naming convention

Project repositories use short, readable, lowercase names with hyphens only when they improve clarity. Product names remain human-friendly and consistent across documentation, releases and future development.

## Repository standards

Each project should progressively include:

- A clear README with purpose, screenshots and feature overview
- Installation or build instructions
- Version/release information
- Technology stack
- Known limitations
- Roadmap or planned improvements when useful
- License information where appropriate
- Clean commit history and descriptive commit messages
